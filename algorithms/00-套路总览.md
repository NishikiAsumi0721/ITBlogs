# Hot 100 套路总览

> **Hot 100 不是 100 道题，是 13 个套路反复用。**
> 目标：60 题覆盖 13 个套路，每个套路练到「看到题 30 秒内知道用哪个」。
> 配套：[README.md](README.md) 记录规范

---

## 按套路学 vs 按题号学

| | 按题号刷 | **按套路刷** |
|---|---|---|
| 顺序 | 1→100 | 同一个套路连做 4-6 题 |
| 效果 | 每道题都是新的 | 第 3 题开始有感觉，第 5 题形成条件反射 |
| 遗忘 | 一周后全忘 | 记住的是模板，能迁移到没见过的题 |
| 面试 | 见过才会 | **没见过也能推** |

**核心方法：一个套路连续做 4-6 题，做完再换下一个。** 不要每天换着花样做。

## 1. 哈希

### 识别信号

- 问「**某个值是否出现过**」
- 问「**找另一半**」（a + b = target）
- 需要**统计频次**（出现几次、最多的元素）
- **去重**（分组、找不重复的）

> 一句话：**空间换时间**，把「遍历查找」变成「O(1) 直接查」。
> 匹配：`HashMap` / `HashSet`

### 模板

```java
// 找另一半
Map<Integer, Integer> seen = new HashMap<>();
for (int i = 0; i < nums.length; i++) {
    int need = target - nums[i];
    if (seen.containsKey(need)) return new int[]{seen.get(need), i};
    seen.put(nums[i], i);     // ★ 先查后存
}

// 统计频次
Map<Integer, Integer> cnt = new HashMap<>();
for (int x : nums) cnt.merge(x, 1, Integer::sum);
```

### 本套路的题

| 题 | 考点 |
|---|---|
| 1. 两数之和 | 找另一半（已做） |
| 49. 字母异位词分组 | 把「字母排序后的串」当 key |
| 128. 最长连续序列 | 用 Set，只在「序列起点」开始数 |
| 169. 多数元素 | 也可用摩尔投票 |

### 易错

- **先查后存**（否则同一元素用两次）
- 数组元素可能是负数，不用特殊处理

## 2. 双指针

### 识别信号

- 数组**已排序**，或**可以排序**（排序是 O(n log n)，值不值看题意）
- 找「**两数/三数之和**」满足某条件
- **原地修改**数组（移除元素、去重、移动零）
- 求「**最大容器/最大面积**」这类两头逼近的题

### 两类双指针（别混）

| 类型 | 指针起点 | 典型 |
|---|---|---|
| **对撞** | 一左一右，向中间逼近 | 三数之和、盛最多水、验证回文 |
| **同向** | 快慢两个指针都从左起 | 移动零、删除有序数组重复项 |

### 模板

```java
// 对撞（前提：有序）
int left = 0, right = n - 1;
while (left < right) {
    int sum = nums[left] + nums[right];
    if (sum == target) { /* 记录 */ left++; right--; }
    else if (sum < target) left++;
    else right--;
}

// 同向（快慢）
int slow = 0;
for (int fast = 0; fast < n; fast++) {
    if (nums[fast] != 0) nums[slow++] = nums[fast];
}
```

### 本套路的题

| 题 | 考点 |
|---|---|
| 283. 移动零 | 同向指针，非零往前挪 |
| 11. 盛最多水的容器 | 对撞，**每次移动矮的那边** |
| 15. 三数之和 | 排序 + 固定一个 + 对撞 + 去重（已做） |
| 42. 接雨水 | 同上思路，但**可跳过**（难） |
| 75. 颜色分类 | 三指针原地分区 |

### 关键洞察

> **三数之和 = 排序 + 固定一个数 + 剩下用两数之和（对撞版）。**
> 排序一次，同时解决「对撞要有序」和「去重」两个问题。

## 3. 滑动窗口

### 识别信号

- 题目出现「**连续子数组 / 子串**」（关键词：连续！）
- 求「最长 / 最短 / 是否包含」满足某条件的**连续区间**
- 扩大窗口和缩小窗口的条件是**单调**的（不会左右摇摆）

> ⚠️ **不连续就不叫滑动窗口**，那是子序列问题（走 DP 或回溯）。

### 模板

```java
int left = 0, right = 0;
Map<Character, Integer> window = new HashMap<>();

while (right < s.length()) {
    char c = s.charAt(right);
    right++;
    // 1. 扩大窗口：更新 window 状态
    window.merge(c, 1, Integer::sum);

    // 2. 缩小窗口：条件不满足时
    while (/* 窗口不合法 */) {
        char d = s.charAt(left);
        left++;
        // 更新 window 状态
    }
    // 3. 更新答案（此时窗口是合法的）
    ans = Math.max(ans, right - left);
}
```

### 本套路的题

| 题 | 考点 |
|---|---|
| 3. 无重复字符的最长子串 | 最经典，必须会默写 |
| 438. 找到字符串中所有字母异位词 | 固定长度窗口 + 频次比较 |
| 76. 最小覆盖子串 | **可跳过**（难） |

### 关键洞察

> **while 里缩窗口，缩到不合法就停；每停一次，当前窗口就是一个候选答案。**
> 记住这个节奏，80% 的滑动窗口题都能套。

## 4. 链表

### 识别信号

- 题干就是链表
- 需要**找中点、判断环** → 快慢指针
- 需要**删除 / 合并 / 插入** → **虚拟头节点（dummy）**
- 需要**反转** → 三个指针迭代

### 三个必会模板

```java
// ① 虚拟头节点（删除、合并必用）
ListNode dummy = new ListNode(0);
dummy.next = head;
ListNode cur = dummy;
while (cur.next != null) { /* ... */ }
return dummy.next;

// ② 快慢指针找中点 / 判环
ListNode slow = head, fast = head;
while (fast != null && fast.next != null) {
    slow = slow.next;
    fast = fast.next.next;
}

// ③ 反转链表
ListNode prev = null, cur = head;
while (cur != null) {
    ListNode next = cur.next;
    cur.next = prev;
    prev = cur;
    cur = next;
}
return prev;
```

### 本套路的题

| 题 | 考点 |
|---|---|
| 160. 相交链表 | 双指针走完各自再走对方 |
| 206. 反转链表 | 模板 ③ |
| 234. 回文链表 | 找中点 + 反转后半 + 比较 |
| 141. 环形链表 | 快慢指针相遇 |
| 142. 环形链表 II | 相遇后从头再来一个慢指针 |
| 21. 合并两个有序链表 | 模板 ① |
| 2. 两数相加 | 模板 ①，注意进位 |
| 19. 删除倒数第 N 个 | 快慢指针隔 N |
| 146. LRU 缓存 | **面试高频**，哈希 + 双向链表 |

### 易错

- 循环条件 `fast != null && fast.next != null`（顺序不能反，否则 NPE）
- 删除节点要先 `dummy`，否则删头节点要特判

## 5. 二叉树

### 识别信号

- 题干是树
- 90% 的题用**递归**就能解
- 问「路径 / 深度 / 祖先 / 子树」→ 想**后序遍历**（先拿子树结果，再处理自己）

### 递归三问（所有树题都用）

```
1. 我要从左右子树拿什么信息？（返回值定义）
2. 我拿到之后怎么处理？（当前节点做什么）
3. 空节点返回什么？（递归出口）
```

### 模板

```java
// 通用递归
public int dfs(TreeNode root) {
    if (root == null) return 0;              // 出口
    int left = dfs(root.left);               // 拿左
    int right = dfs(root.right);             // 拿右
    /* 处理当前节点 */                        // 处理
    return /* 给父节点的信息 */;
}

// 层序遍历（BFS）
Queue<TreeNode> q = new LinkedList<>();
q.offer(root);
while (!q.isEmpty()) {
    int size = q.size();                     // ★ 先记 size
    while (size-- > 0) {
        TreeNode node = q.poll();
        if (node.left != null) q.offer(node.left);
        if (node.right != null) q.offer(node.right);
    }
}
```

### 本套路的题（10 题，最划算的套路）

| 题 | 考点 |
|---|---|
| 94. 中序遍历 | 递归 / 迭代 |
| 104. 最大深度 | 递归入门 |
| 226. 翻转二叉树 | 递归入门 |
| 101. 对称二叉树 | 双树递归 |
| 543. 二叉树的直径 | **后序 + 全局变量** |
| 102. 层序遍历 | BFS 模板 |
| 108. 有序数组转 BST | 二分 + 递归 |
| 98. 验证 BST | **中序有序** 或 上下界 |
| 230. BST 第 K 小 | 中序遍历计数 |
| 236. 最近公共祖先 | 后序，判断左右是否都找到 |

### 关键洞察

> **树题 80% 是「后序遍历 + 全局变量」。** 因为要的信息在子树里，得先拿到子树的答案才能算自己的。
> 看到「直径 / 最大路径和 / 最长同值路径」这类，直接想：**用一个全局变量记答案，递归只返回「以我为起点」的值。**

## 6. 二分查找

### 识别信号

- 数组**有序**（或部分有序，如旋转数组）
- 题目出现「**最小值的最大值 / 最大值的最小值**」→ **对答案二分**
- 找「第一个 / 最后一个」满足条件的位置

### 模板（记这一个就够）

```java
// 找左边界（第一个 >= target 的位置）
int lo = 0, hi = nums.length;         // ★ 注意是 length，不是 length-1
while (lo < hi) {
    int mid = lo + (hi - lo) / 2;     // ★ 防溢出写法
    if (nums[mid] < target) lo = mid + 1;
    else hi = mid;
}
return lo;                             // 可能是 length（表示没找到）
```

### 本套路的题

| 题 | 考点 |
|---|---|
| 35. 搜索插入位置 | 左边界模板 |
| 74. 搜索二维矩阵 | 二维转一维下标 |
| 34. 查找第一个和最后一个位置 | 左边界 + 右边界 |
| 33. 搜索旋转排序数组 | 判断哪半边有序 |

### 三个坑

1. `mid = lo + (hi - lo) / 2` 而不是 `(lo + hi) / 2`（防溢出）
2. `while (lo < hi)` 而不是 `<=`（配合 `hi = length`）
3. 死循环：`hi = mid` 或 `lo = mid + 1`，**不能是 `lo = mid`**

## 7. 栈

### 识别信号

- **括号 / 表达式**匹配
- **「下一个更大/更小元素」** → **单调栈**
- 需要「最近的」「上一个」这类回溯性查询
- 撤销操作

### 模板

```java
// 单调栈：找右边第一个更大的元素
int[] res = new int[n];
Deque<Integer> stack = new ArrayDeque<>();  // 存下标
for (int i = 0; i < n; i++) {
    while (!stack.isEmpty() && nums[stack.peek()] < nums[i]) {
        int idx = stack.pop();
        res[idx] = nums[i];                  // i 就是 idx 右边第一个更大的
    }
    stack.push(i);
}
```

### 本套路的题

| 题 | 考点 |
|---|---|
| 20. 有效括号 | 栈的入门 |
| 155. 最小栈 | 辅助栈存最小值 |
| 394. 字符串解码 | 双栈（数字 + 字符串） |
| 739. 每日温度 | **单调栈模板题** |
| 84. 柱状图中最大矩形 | **可跳过**（难） |

### 关键洞察

> **单调栈解决的是「找右边第一个比我大/小的元素」。**
> 栈里存**下标**不存值（因为要回填结果）。入栈前把「比自己小的都弹出去」，弹出的那一刻就找到了答案。

## 8. 动态规划

### 识别信号

- 求「**最优解**」（最大/最小）或「**方案数**」
- 问题能**拆成规模更小的同类子问题**
- 有**重叠子问题**（暴力递归会重复算）
- 关键词：「多少种方法」「最长/最短」「能否」

### 五步法（每道 DP 题都走这五步，别跳）

```
1. 定义 dp[i] 的含义 —— 一句话说清
2. 找状态转移方程 —— dp[i] 由哪些 dp[?] 推出来
3. 初始化 —— dp[0] / dp[1] 是什么
4. 遍历顺序 —— 从小到大？还是从后往前（如 0-1 背包）
5. 举例验证 —— 手算 dp[2]、dp[3] 对不对
```

> **第 1 步是分水岭。** 定义错了，后面全错。「dp[i] = 以 i 结尾的最长X」和「dp[i] = 前 i 个里的最长X」是两种完全不同的题。

### 题单（按难度递进，别跳着做）

| 阶段 | 题 |
|---|---|
| 入门 | 70. 爬楼梯、118. 杨辉三角 |
| 一维 | 198. 打家劫舍、322. 零钱兑换 |
| 序列 | 300. 最长递增子序列、152. 乘积最大子数组 |
| 二维 | 62. 不同路径、64. 最小路径和 |
| 字符串 | 5. 最长回文子串、1143. 最长公共子序列 |
| 可选 | 139. 单词拆分、416. 分割等和子集（背包） |

### 关键洞察

> **DP 题难在「定义状态」，不难在写代码。**
> 如果卡住，就问自己：**「我要的答案，用什么最少的变量能唯一描述？」**
> 比如「最长递增子序列」要描述「以 i 结尾」而不是「前 i 个」，否则递推不了。

### 跳过

- 72. 编辑距离（难，可后做）
- 32. 最长有效括号
- 10. 正则表达式匹配

## 9. 回溯

### 识别信号

- 求「**所有**可能的组合 / 排列 / 方案」
- 需要**枚举决策树**（选或不选、选哪个）
- 题干里有「请你返回所有」「列出全部」

> 和 DP 的区别：**DP 求最优/数量，回溯求具体方案。**

### 模板（背这一个）

```java
void backtrack(路径, 选择列表) {
    if (满足结束条件) {
        res.add(new ArrayList<>(路径));   // ★ 必须新建副本
        return;
    }
    for (选择 : 选择列表) {
        if (/* 剪枝条件 */) continue;
        路径.add(选择);
        backtrack(路径, 新选择列表);
        路径.remove(路径.size() - 1);      // ★ 撤销
    }
}
```

### 本套路的题

| 题 | 考点 |
|---|---|
| 46. 全排列 | 最基础，必须会 |
| 78. 子集 | 每个元素选/不选 |
| 17. 电话号码字母组合 | 多层选择 |
| 39. 组合总和 | **可重复选**，注意去重 |
| 22. 括号生成 | 左右括号数量约束 |
| 79. 单词搜索 | 二维网格 DFS + 标记 |

### 三个坑

1. `res.add(path)` 不新建副本 → 最后全是空列表（同链表那个引用坑）
2. 忘记 `remove` 撤销 → 路径越来越长
3. 组合类题目要去重时，先排序，再判断 `i > start && nums[i] == nums[i-1]`

### 跳过

- 51. N 皇后（难，但套路一样）
- 131. 分割回文串（可后做）

## 10. 普通数组与矩阵

### 识别信号

- **原地修改**（O(1) 空间）→ 想「把数组当哈希表用」或「用下标做标记」
- **区间合并** → 先按左端点排序
- **矩阵** → 注意边界和遍历顺序

### 本套路的题

| 题 | 考点 |
|---|---|
| 53. 最大子数组和 | 贪心 / DP（Kadane） |
| 56. 合并区间 | 按左端点排序后合并 |
| 189. 轮转数组 | 三次反转 |
| 238. 除自身以外数组的乘积 | 前缀积 × 后缀积 |
| 41. 缺失的第一个正数 | **把数组当哈希表**（难，可跳过） |
| 73. 矩阵置零 | 用第一行第一列做标记 |
| 54. 螺旋矩阵 | 四边界收缩 |
| 48. 旋转图像 | 转置 + 翻转 |

### 关键洞察

> **「原地修改 + O(1) 空间」的题，套路几乎都是「把数组本身当下标哈希表」。**
> 思路：让 `nums[i]` 出现在下标 `i` 的位置上，然后扫一遍看谁不在位置上。

## 11. 堆

### 识别信号

- 求「**前 K 个**」最大/最小/高频
- 求「**中位数**」（对顶堆）
- **流式数据**，边来边求

### 模板

```java
// 前 K 大 → 用小顶堆，堆大小保持 K
PriorityQueue<Integer> pq = new PriorityQueue<>();  // 默认小顶堆
for (int x : nums) {
    pq.offer(x);
    if (pq.size() > k) pq.poll();     // 弹出最小的
}
return pq.peek();                      // 堆顶就是第 K 大
```

### 本套路的题

| 题 | 考点 |
|---|---|
| 215. 数组中的第 K 个最大元素 | 小顶堆 / 快排分区 |
| 347. 前 K 个高频元素 | 哈希统计 + 堆 |
| 295. 数据流的中位数 | 对顶堆（大顶堆 + 小顶堆） |

### 关键洞察

> **求前 K 大 → 用小顶堆（堆里留最大的 K 个，堆顶是第 K 大）。**
> 反直觉但必须记住：**求最大用最小堆。**

## 12. 图

### 识别信号

- **二维网格**遍历（岛屿、连通块）→ DFS/BFS
- **依赖关系 / 先后顺序** → 拓扑排序
- 「**能否走通**」→ BFS 最短路径

### 模板

```java
// 网格 DFS（岛屿数量）
void dfs(char[][] grid, int i, int j) {
    if (i < 0 || i >= m || j < 0 || j >= n || grid[i][j] != '1') return;
    grid[i][j] = '0';                    // ★ 访问过就标记，防止重复
    dfs(grid, i + 1, j);
    dfs(grid, i - 1, j);
    dfs(grid, i, j + 1);
    dfs(grid, i, j - 1);
}
```

### 本套路的题

| 题 | 考点 |
|---|---|
| 200. 岛屿数量 | 网格 DFS 入门 |
| 994. 腐烂的橘子 | 多源 BFS（层数 = 时间） |
| 207. 课程表 | 拓扑排序（BFS 入度法） |

**只做这 3 题，理解套路就够。** 再难的不在你的面试范围。

## 13. 贪心与技巧

### 识别信号

- **贪心**：每步取局部最优，且能证明不会更差（如「买卖股票」「跳跃游戏」）
- **技巧**：位运算、摩尔投票、原地哈希

### 本套路的题

| 题 | 考点 |
|---|---|
| 121. 买卖股票的最佳时机 | 维护历史最低价 |
| 55. 跳跃游戏 | 维护最远可达位置 |
| 45. 跳跃游戏 II | 同上，记跳几次 |
| 136. 只出现一次的数字 | **异或**（a^a=0, a^0=a） |
| 169. 多数元素 | 摩尔投票 |

### 关键洞察

> **贪心不需要证明也很难证，面试时能说出「为什么局部最优能推全局」就够。**
> 异或那条：`a ^ a = 0`、`a ^ 0 = a`、异或满足交换律 —— 所以成对出现的都消掉了。
