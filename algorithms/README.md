## 记录格式

每道题一个 md 文件，命名 `题号-题名.md`，包含：

| 字段 | 说明 |
|---|---|
| 难度 | 简单 / 中等 / 困难 |
| 我的解法 | 自己第一版写出来的代码 |
| 复杂度 | 时间 / 空间 |
| 不足 | 这版哪里不够好 |
| 更优解 | 标准答案，附关键代码 |
| **关键洞察** | 一句话说清"这题的转折点在哪" |
| 易错点 | 我踩过或差点踩的坑 |

## 三档标记法

每道题做完标一档，复习时只刷「见过」和「不会」：

- **会** —— 不看题解能默写
- **见过** —— 记得思路，写不全
- **不会** —— 看完题解也没完全理解

> 同一个专题刷 20 题「见过」，不如 8 题「会」。
