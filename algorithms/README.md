## 记录格式

每道题一个 md 文件，命名 `题号-题名.md`，包含：

| 字段 | 说明 |
|---|---|
| 难度 | 简单 / 中等 / 困难 |
| 我的解法 | 自己第一版写出来的代码 |
| 复杂度 | 时间 / 空间 |
| 不足 | 这版哪里不够好 |
| 更优解 | 标准答案，附关键代码 |
| **关键洞察** | 一句话说清"这题的转折点在哪" |
| 易错点 | 我踩过或差点踩的坑 |

## 已踩过的坑（跨题汇总）

### 语法 / 语言层

| 坑 | 出现在 | 说明 |
|---|---|---|
| `new List<>()` | 三数之和 v1 | 接口不能实例化，用 `ArrayList` |
| `res.add(list)` 存引用 | 两数之和、三数之和 | 必须 `new ArrayList<>(list)` 存副本 |
| 循环条件写反致 NPE | — | `fast != null && fast.next != null` 顺序不能反 |

### 算法逻辑层

| 坑 | 出现在 | 说明 |
|---|---|---|
| **找到答案就 break** | 三数之和 v5 | 求「全部答案」的题必须穷尽 |
| **去重放循环开头** | 三数之和 v5 | 应放在命中之后 |
| 用 for + 独立 if 代替 while | 三数之和 v4 | 双指针要反复移动，`if` 只判一次 |
| **`if` 代替 `while` 收缩窗口** | 无重复子串 v2 | 「缩到……为止」必须是 while |
| **用 `Set` 判异位词** | 字母异位词 v1 | 丢次数 → `"aab"` 和 `"abb"` 判为相同 |
| **`Iterator.next()` 调两次** | 字母异位词 v1 | 删错元素 + 抛 `NoSuchElementException` |
| **`substring` 每个窗口复制一次** | 字母异位词 v2 | O(n·m)，改用下标增量更新 |
| **先改指针后存后继** | 反转链表 v1 | 断链 → 成环 |
| **`&&` 连对象** | 反转链表 v1 | `head.next && ...` 在 Java 里编译不过 |
| **有负数还用滑动窗口** | 和为 K 的子数组 v1 | 单调性失效 → 应该用前缀和 |
| **`while` 里用不变量累加** | 和为 K 的子数组 v1 | `sum += nums[i]` 中 `i` 不变，元素为 0 时死循环 |
| 对撞 / 同向双指针混用 | — | 两种形态的移动依据完全不同 |
| 数组当集合用（`char[]` 调 `add`） | 无重复子串 v1 | 定长、无 add/contains，换 Set/Map |

### 代码结构层（反复犯 ⚠️）

| 坑 | 出现在 | 说明 |
|---|---|---|
| **边界判断写在取值后面** | 移动零 | `nums[left]!=0 && left<n` 应先判 `left<n` |
| **手动搜索位置导致处处越界** | 移动零 | 改成「收集非零」，边界问题消失 |
| **为防越界人为缩一格** | 移动零、无重复子串 | 改用自然的 `length` |
| **写了永远执行不到的死代码** | 移动零、盛最多水 | 删一行测试：删掉还对 = 多余 |
| **声明了但没用的变量** | 字母异位词 v3 | `char[] a` 声明后从未引用 |
| **习惯性加多余 guard** | 移动零、盛最多水、三数之和（共 5 次） | ✅ **无重复子串已改掉** → [详见](00-代码习惯-习惯性加防御.md) |
| **复制粘贴没改全变量** | 字母异位词 v2 | 恒返回 true → [详见第二类问题](00-代码习惯-习惯性加防御.md#第二类问题复制粘贴没改全) |

> **结构层的坑最值得警惕**——它们不是"写错"，是"习惯"。每次写代码前扫一眼这一栏。

## 三档标记法

每道题做完标一档，复习时只刷「见过」和「不会」：

- **会** —— 不看题解能默写
- **见过** —— 记得思路，写不全
- **不会** —— 看完题解也没完全理解

> 同一个专题刷 20 题「见过」，不如 8 题「会」。
